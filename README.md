# 生物医学数据科学 PBL 课程仓库

按课程主题归档课件、数据、工作纸、作业、分析代码、结果和 AI 协作记录。
整理日期：2026-11-18。

## 目录约定

```text
biomedical-data-science-pbl/
|-- README.md
|-- course/                 课程大纲、评分标准与仓库提交要求
|-- lessons/
|   `-- <编号>-<主题>/
|       |-- README.md       研究问题、证据链、运行命令和完成状态
|       |-- slides/         教师课件与阅读材料
|       |-- pbl/            工作纸、任务说明和参考资料
|       |-- data/           课程数据、来源说明和字段文档
|       |-- src/            分析代码与文档生成代码
|       |-- notebooks/      教师或学生 Notebook，来源分别标明
|       |-- outputs/        实验结果、图表与机器可读结果
|       |-- homework/       已完成作业和演讲材料
|       |-- ai-dialogues/   真实可见对话的脱敏导出
|       `-- reflection.md   复现情况、限制与尚待完成事项
|-- provenance/            文件清单、来源、哈希与归档说明
`-- tools/                 仓库校验与统一运行入口
```

原始资料与已完成作业将保留来源和版本，不把参考答案当作学生作业，
也不把新生成说明冒充历史 AI 对话。仅收录本课程相关的可见用户消息和
助手回复，不导出系统提示、开发者提示、隐藏推理或本机凭据。

包含课程资料和医学教学数据，默认应创建私有仓库。公开传播前需核对
教师授权、各数据集许可和个人信息；当前目录不是一份公开再授权声明。
