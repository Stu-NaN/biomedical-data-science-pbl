### 3.【高｜数学条件】小 gamma 线性近似：条件不完整，结论写得太虚

- 原：「当相关点对满足 γ‖z−u‖²≪1 时，RBF 可作一阶展开；利用 Σαᵢyᵢ=0，主要有效项近似为 2γzᵀu，另一些项被抵消或吸收进截距。固定 C 时，减小 gamma 也可能使有效拟合变弱。这是有条件的近似，不表示所有小 gamma RBF 都严格等价于某个线性模型。」
- 问题：(a) 条件没有说清是哪些点对；(b) 本数据其实有点对不满足条件；(c)"也可能使有效拟合变弱"丢掉了推导的核心结论，近似成立时 C 的换算是确定的。
- 改：「若参与求解的训练点之间、以及支持向量与待预测点之间都满足 γ‖z−u‖²≪1，就有 exp(−γ‖z−u‖²)≈1−γ‖z‖²−γ‖u‖²+2γzᵀu。由于 Σαᵢyᵢ=0，常数项和只含待预测点的项相互抵消，只含训练点的项并入 b，剩下的是 2γΣαᵢyᵢzᵢᵀz。代回对偶问题可得：此时 RBF(C, γ) 近似等于 C′=2γC 的线性 SVM。γ=0.01、C=1 对应 C′≈0.02，与表 6 中 C=0.01 的线性模型一样全判 AB；网格中 γ=0.01、C=100（C′≈2）的验证敏感度、特异度和 BA（0.619 / 0.90 / 0.760）与 linear C=1 完全相同。图 4 左上与图 3 左图形态几乎一样，反映的也是同一件事。不过这个条件在本数据中并不处处成立：滑脱程度为 418 的 V116 标准化后离多数点约 10 个标准差，γ=0.01 时它与其他点的 γd² 约为 1。所以这是有数据支持的近似，不是严格等价。」

### 7.【中｜自然中文】免责句过多，"不能……也不能……"的句式反复出现，像模板

只保留三处必要的限定（验证不等于测试、score 不是概率、人工噪声不等于真实误差），其余删掉或合并。示例：

- 「这个判断针对当前参数和数据，不是说 RBF 一定比线性核差。」→ 删去，或改为「过拟合的是 C=100、γ=10 这组参数。」
- 「这个结果只适用于当前拟合边界和噪声设定，不能推广为所有 RBF 都更脆弱。」→「这是这组 RBF 参数在人工噪声下的表现。」
- 「这里不需要声称所有 SVM 都必须用 StandardScaler；若特征已处在有意义的统一尺度，或另有合理的尺度设计，也可采用别的预处理。关键是距离和正则所隐含的尺度必须符合问题。」→「标准化不是唯一的办法，关键是让距离的尺度符合问题本身。」
- 「边界有相似之处，但并无必须相似的理论要求。」→「两者边界相近，是因为两类的主要分界本来就沿滑脱程度方向，弯不弯影响不大。」
- 「测试前没有必要把其中一个写成绝对赢家。」→ 删去（工作单本来就不要求选冠军）。
- 「与逻辑回归比较时……固定样本数和归一化约定后，C 越大才对应相对更弱的正则。」→「逻辑回归也是"损失 + L2 正则"，只是把损失换成了对数损失；在 scikit-learn 的写法里，C 越大，正则越弱。」
- 「RBF 有无限维的特征空间表示，精确核计算不必显式列出它；若样本量很大，也存在有限维近似映射，并非只能做精确核计算。」→「RBF 对应的特征空间是无限维的，只能通过核函数来算；样本量很大时，可以改用随机特征等有限维近似。」

- 改：「数据线性可分时，只要 C 不小于硬间隔解中最大的 α，软间隔解就与硬间隔解相同。八点例子中 α=0.546，远小于 10000，所以第二节用 C=10000 得到的就是硬间隔解（在求解容差内）。数据不可分时，C 再大也到不了硬间隔：完整训练集在 C=100 时仍有 35 个训练错误，矛盾数据则根本没有硬间隔可行解。」

### 10.【中｜答题完整度】第十节没有把"一个优势、一个局限及其发生条件"成对写清

现在写的限制（两项输入区分不了 DH 和 NO）是数据层面的问题，不是 SVM 本身的局限。建议改成：

- 局限：「对输入尺度敏感。特征单位不统一，又直接用基于欧氏距离的核时，结果会被某一维主导：不标准化而把 x1 乘 100，验证 BA 从 0.705 降到 0.488（表 10）。」
- DH 与 NO 重叠的问题保留，单独写成一句"数据层面的限制"。
