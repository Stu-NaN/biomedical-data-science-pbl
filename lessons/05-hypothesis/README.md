## 运行

在仓库根目录安装 `requirements-lock.txt` 后运行：

```console
python lessons/05-hypothesis/src/analyze.py
```

`src/history` 是原任务生成代码的存档，不承诺直接运行；部分依赖原本机路径、
Office 渲染环境、Node 工具或教师标签。新增入口不依赖这些条件。
